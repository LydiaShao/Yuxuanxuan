# Yuxuanxuan

西幻职业图文站。顶栏用英文切换职业，每一页是一个职业：一张横版插图、一枚方邮票头像，加上文字。

网站主题色、每个职业的印象色，以及图片，都在管理员后台里改，不用改代码。

## 启动

```bash
python3 server.py
```

前台：http://127.0.0.1:4173

后台：http://127.0.0.1:4173/admin

第一次打开后台时设置管理员密码（至少 8 位）。密码存在本机的 `data/admin.json`，不会提交到仓库。

## 后台里可以做的事

- 改网站主题色。所有职业共用这一色，用在顶栏、按钮和页面点缀上
- 添加、排序、删除职业。顶栏名称用英文。每个职业可以自选印象色，只用在这一页的画框和头像边上
- 为每个职业上传横版插图和方邮票头像（JPG、PNG、WEBP、GIF）。原文件保存，不压缩，不限制大小。想保持无损请用 PNG
- 写一句短文和正文。正文里用空行分段

上传的图片在 `images/uploads/`，站点内容在 `data/site.json`。
