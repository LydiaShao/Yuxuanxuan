# Yuxuanxuan

西幻职业图文站。顶栏用英文切换职业，每一页是一个职业：横版插图、方邮票头像，以及这一页上的其他图片，加上文字。前两张是固定位置，可以不传。

没有全站统一配色。每个职业自己一套：页面背景同时是横图底部的渐变，顶栏是另一种颜色。文字板块还能单独上色。登录后直接在网页上改图片和文字。游客只能浏览，也可以拖动和旋转小人。

## 启动

```bash
python3 server.py
```

前台：http://127.0.0.1:4173

后台：http://127.0.0.1:4173/admin

第一次打开后台时设置管理员密码（至少 8 位）。密码存在本机的 `data/admin.json`，不会提交到仓库。

## 后台里可以做的事

- 登录以后回到网页编辑。可以改当前职业的页面背景、顶栏、顶栏文字、文字和次要文字
- 邮票和职业名可以靠左或靠右，不居中。靠右时邮票在右、名字在左
- 加文字板块，每块单独设底色和文字颜色
- 上传横图、邮票、画廊图片，以及不跟页面滚动的小人。小人可以拖动，也可以每次转 90°。游客的拖动和旋转不会保存
- 图片按原文件保存，不压缩，不限制大小。想保持动图和无损，请用 GIF 或 PNG

上传的图片在 `images/uploads/`，站点内容在 `data/site.json`。
