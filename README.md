# Yuxuanxuan

西幻职业图文站。顶栏用英文切换职业，每一页是一个职业：横版插图、方邮票头像，以及这一页上的其他图片，加上文字。前两张是固定位置，可以不传。

网站和每个职业页面上的颜色，以及图片，都在管理员后台里改，不用改代码。默认是一套薄荷绿。

## 启动

```bash
python3 server.py
```

前台：http://127.0.0.1:4173

后台：http://127.0.0.1:4173/admin

第一次打开后台时设置管理员密码（至少 8 位）。密码存在本机的 `data/admin.json`，不会提交到仓库。

## 后台里可以做的事

- 改网站配色：背景、面板、文字、次要文字、点缀、按钮文字。这些颜色直接用在顶栏和页面上
- 添加、排序、删除职业。顶栏名称用英文。每个职业单独改页面背景、横图底部的渐变、文字和次要文字
- 为每个职业上传横版插图、方邮票头像，以及更多图片（JPG、PNG、WEBP、GIF）。缺了前两张也不会在前台报错。原文件保存，不压缩，不限制大小。想保持无损请用 PNG
- 写一句短文和正文。正文里用空行分段

上传的图片在 `images/uploads/`，站点内容在 `data/site.json`。
